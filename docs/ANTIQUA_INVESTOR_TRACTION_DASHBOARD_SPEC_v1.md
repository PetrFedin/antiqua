# ANTIQUA Investor Traction Dashboard v1

**Status:** SPECIFICATION FOR EVIDENCE-BASED MVP DASHBOARD

## 1. Principle

The dashboard separates:
- product capability;
- user behavior;
- partner pipeline;
- paid commercial evidence;
- economics;
- infrastructure readiness.

No placeholder metric may visually resemble real traction.

## 2. Executive strip

Show:
- production readiness;
- active real pilots;
- paid pilots;
- cash received;
- active paid partners;
- D30 retained paid partners;
- eligible completed GMV;
- recurring revenue share.

Each metric has:
- value;
- period;
- source;
- evidence status;
- last refresh.

## 3. Funnel

`qualified partner -> proposal -> accepted scope -> paid pilot -> completed pilot -> renewed / expanded`

Required conversion rates:
- proposal / qualified;
- accepted / proposal;
- paid / accepted;
- completed / paid;
- renewed / eligible completed.

## 4. Pricing panel

By revenue stream:
- quotes;
- accepted quotes;
- paid contracts;
- median accepted price;
- realized price ratio;
- renewal price change;
- confidence level.

## 5. Consumer traction

- authenticated WAU / MAU;
- D7 / D30 retention;
- artwork opens per active user;
- artwork -> artist continuation;
- saves / artwork opens;
- research depth;
- collection add rate;
- event-plan rate;
- eligible inquiry rate.

## 6. Partner value

- qualified leads;
- response coverage;
- median response time;
- viewing rate;
- offer rate;
- won rate;
- D30 demand retention.

## 7. Unit economics

Only after source data exists:
- partner acquisition cost;
- onboarding cost;
- support cost;
- direct infra/provider cost;
- gross contribution;
- gross margin;
- CAC payback;
- retained revenue.

## 8. Revenue quality

Separate:
- one-time project revenue;
- recurring subscription revenue;
- usage/transaction revenue;
- sponsorship/activation revenue;
- institutional licence revenue.

## 9. Evidence state badges

- VERIFIED CASH;
- CONTRACTED;
- INVOICED;
- WRITTEN ACCEPTANCE;
- PILOT TELEMETRY;
- PRODUCT CAPABILITY;
- ASSUMPTION;
- MISSING.

## 10. Investor milestones

### Gate A — Working product
Consumer and professional golden paths work.

### Gate B — Paid validation
At least one real counterparty pays.

### Gate C — Repeatability
Multiple independent paid partners accept comparable economics.

### Gate D — Retention
Renewal/expansion evidence exists.

### Gate E — Unit economics
CAC, cost-to-serve and gross contribution can be measured.

### Gate F — Scale
Acquisition and delivery can expand without linear cost growth.
