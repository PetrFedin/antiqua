# ANTIQUA — Artwork Experience Wave 1

**Статус:** готово к реализации после merge #112  
**Язык:** русский по умолчанию, полноценный английский через EN  
**Фокус:** пользовательский интерес, исследовательская глубина, визуальная наглядность

## Цель

Превратить Досье произведения из набора секций в последовательный исследовательский маршрут:

Галерея
→ Произведение
→ История произведения
→ Провенанс
→ Карта доказательств
→ Открытые вопросы исследования
→ Художник
→ Связанные произведения
→ Коллекция

## 1. История произведения

Единая визуальная хронология из уже существующих фактов.

Типы событий:
- создание / датировка;
- провенанс;
- выставка;
- публикация;
- изменение атрибуции;
- каталожная редакция;
- состояние;
- реставрация;
- рыночный контекст.

Каждое событие показывает:
- дату или «дата не установлена»;
- тип;
- краткое описание;
- источник;
- статус проверки;
- переход в соответствующий раздел Досье.

Запрещено:
- угадывать даты;
- смешивать рыночный факт и факт атрибуции;
- показывать частные данные владельца;
- создавать ложную непрерывность там, где есть пробел.

## 2. Карта доказательств

Шесть измерений:
- Атрибуция;
- Провенанс;
- Библиография;
- Выставочная история;
- Редакции исследования;
- Рыночные аналоги.

Состояния:
- Есть;
- Частично;
- Нет данных.

Каждая карточка показывает:
- число связанных записей;
- краткое пояснение;
- что отсутствует;
- действие «Перейти к разделу».

Никакого общего процента «достоверности».

## 3. Открытые вопросы исследования

Выводятся как самостоятельные карточки.

Примеры:
- Пробел в провенансе: 1941–1957;
- Нет проверенной библиографии;
- Не подтверждена выставочная история до 1980 года;
- Не хватает источника для текущей атрибуции;
- Недостаточно сопоставимых продаж.

Публичная версия:
- показывает вопрос;
- не раскрывает приватные документы;
- не обещает экспертный вывод.

Профессиональная версия позже:
- назначение эксперта;
- вклад источника;
- рецензирование;
- закрытие вопроса с историей изменений.

## 4. Связанные произведения

Каждая рекомендация обязана отвечать на вопрос:

«Почему эта работа показана?»

Причины:
- тот же художник;
- тот же период;
- та же техника;
- тот же материал / основа;
- общая выставка;
- общий ансамбль;
- связанная коллекция;
- близкое направление вкуса.

Цена не считается художественным сходством.

## 5. Страница художника

Первый экран:
- имя;
- годы жизни / деятельности;
- основные техники;
- краткая биография;
- статус профиля;
- число произведений в ANTIQUA;
- число источников;
- выставочный контекст.

Далее:
- хронология;
- произведения;
- выставки;
- публикации;
- связанные исследования;
- представительство;
- связанные художники / школы только при доказуемой связи.

## 6. Визуальная коллекция

Режимы:
- Стена;
- По художникам;
- По периодам;
- По технике;
- По материалу;
- Хронология.

Карточка коллекции:
- обложка;
- название;
- кураторское описание;
- число работ;
- ключевые направления.

Приватные поля:
- стоимость;
- страховка;
- место хранения;
- владелец;

не попадают в публичный слой.

## 7. Мобильный интерфейс

На iPhone:
- изображение первым;
- нижняя панель: Сохранить / Исследовать / коммерческое действие только при наличии sale state;
- вертикальная история произведения;
- горизонтальная карта доказательств;
- связанные работы свайпом;
- никаких поздних блоков, сдвигающих активную кнопку;
- нижняя навигация не перекрывает CTA.

На планшете:
- изображение + факты в два столбца;
- исследование и связанные работы рядом при достаточной ширине.

На desktop:
- крупное изображение;
- research rail;
- история и доказательства без dashboard-перегруза.

## 8. Производительность

- резервировать высоту асинхронных блоков;
- lazy-load вторичных изображений;
- primary image загружать приоритетно;
- skeleton вместо скачка;
- измерять CLS;
- не монтировать аналитику перед активными действиями.

## 10. Приёмочный маршрут

Галерея
→ открыть произведение
→ увеличить изображение
→ понять автора / дату / технику
→ открыть историю
→ проверить провенанс
→ увидеть пробелы
→ открыть вопрос исследования
→ перейти к художнику
→ открыть связанную работу
→ сохранить
→ добавить в коллекцию

Маршрут должен пройти на:
- 390×844;
- 834×1112;
- 1440×1000.

## 11. Метрики после запуска

Измерять, но не интерпретировать как причинность без основания:
- глубина Досье;
- доля переходов в Историю;
- доля открытий Карты доказательств;
- доля переходов к художнику;
- доля переходов в связанные работы;
- сохранения;
- добавления в коллекции;
- возврат D7;
- возврат D30.
